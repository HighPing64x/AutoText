# AutoText模拟打字

## 介绍
这是一个用于模拟用户进行打字的程序。
本项目使用了AI

## 使用说明
此说明对应当前项目代码（WPF 程序），功能包括：从程序根目录下的 `Data` 文件夹选择 .txt 文件，预览并将内容发送到其他程序的输入框或聊天栏。支持两种发送方式：逐字符模拟键入（`SendInput`）和剪贴板粘贴（Ctrl+V）。支持全局热键、锁定目标窗口、延迟配置、循环发送与简单编码识别。

### 快速上手
1. 将要发送的 `.txt` 文件放入程序根目录下的 `Data` 文件夹（程序启动时会自动创建并扫描）。
2. 启动程序，切换到“导入（预览）”标签页，选择要发送的文件，右侧会自动预览并显示检测到的编码。
3. 在“设置”页配置：
   - 目标窗口选择：使用“发送到当前窗口”则在倒计时期间切换到目标程序并把光标放在输入框；使用“锁定特定窗口”可在目标程序激活后点击“锁定当前窗口”保存目标（仅保存窗口标题与句柄用于会话）。
   - 发送方式：选择“逐字符 SendInput”或“剪贴板粘贴（Ctrl+V）”。
   - 设置每字符延迟、换行停顿、是否循环等。
   - 是否启用全局热键（默认 Ctrl+Shift+T）以及触发前倒计时秒数。
4. 回到“主页”页，确认选中文件后点击“开始（发送）”或按热键开始。开始后按钮变为“停止”，再次点击或按热键可停止发送。

### 注意事项（重要）
- 如果目标程序以管理员权限运行，而本程序没有提升（非管理员），Windows 会阻止模拟输入或 SetForegroundWindow 使其失效。尽量以相同权限运行两者。
- `SendInput` 模式在大多数桌面程序（记事本、VSCode 等）下更稳定；剪贴板模式依赖目标窗口获得输入焦点并能响应 Ctrl+V，程序会在必要时尝试把目标置于前台并进行一次点击以确保焦点。
- 若使用“窗口置顶（Topmost）”，发送前会短暂取消置顶以允许目标获得焦点；若你希望一直置顶可在发送结束后恢复。
- 如果遇到鼠标短暂移动并点击，这属于程序为确保焦点而做的一次性操作；若不希望此行为，请在设置里取消置顶并尽量手动切换到目标窗口的输入框后再触发。

### settings.ini（位置与格式）
- 路径：程序根目录（与可执行文件同目录）下的 `settings.ini`
- 格式：纯文本 INI 格式，支持若干节（Section）和 `key=value` 对。程序会读取与写入以下节与键。

### INI 各节与键详解

[General]
- LastFile
  - 含义：上次选中的文件名（仅文件名，不含路径）。
  - 用途：程序启动或刷新文件列表时尝试自动恢复上次选中文件。
  - 示例：`LastFile=example.txt`
- TopMost
  - 含义：程序窗口是否默认置顶。
  - 值：`true` 或 `false`
  - 说明：若为 `true`，窗口会置顶；发送过程中程序短暂取消置顶以允许目标获取焦点，然后恢复。
[Target]
- TargetMode
  - 含义：目标窗口选择模式。
  - 值：`Active` 或 `Locked`
  - 说明：`Active` 表示发送到当前活动窗口（倒计时期间请手动切换焦点到目标程序）。`Locked` 表示发送到程序已锁定的特定窗口（需先使用“锁定当前窗口”）。
- LockEnabled
  - 含义：是否已锁定目标窗口（布尔值）。
  - 值：`true` 或 `false`
  - 说明：仅供显示与逻辑判断，句柄在程序会话间可能失效（程序会保存窗口标题以供参考）。
- LockedWindowTitle
  - 含义：被锁定窗口的标题（字符串）。
  - 用途：用于在 UI 上展示已锁定的目标窗口（实际发送使用句柄 `_lockedWindowHandle`）。
[Sending]
- Method
  - 含义：发送方式。
  - 值：`SendInput` 或 `Clipboard`
  - 说明：`SendInput` 使用 Windows API 逐字符发送 Unicode 键（更拟真）；`Clipboard` 先把整行复制到剪贴板再发送 Ctrl+V（适合长文本但依赖目标能接收粘贴）。
[Timing]
- DelayMin
  - 含义：每字符最小延迟（毫秒）。
  - 类型：整数（例：`50`）
- DelayMax
  - 含义：每字符最大延迟（毫秒）。
  - 类型：整数（例：`150`）
  - 说明：若 `DelayMin` != `DelayMax`，程序会在区间内随机延迟，模拟真实输入节奏。若两者相同则为固定间隔。
- LinePause
  - 含义：每行发送后额外停顿（毫秒）。
  - 类型：整数（例：`200`）
  - 说明：在发送完一行并回车后暂停，避免发送过快。
- SimulateTypos
  - 含义：是否启用“模拟错别字并回退”的简易模拟（布尔）。
  - 值：`true` 或 `false`
  - 说明：当前版本占位（UI 有该选项），如需实现可扩展为随机插入错字并发送退格修正。
[Behavior]
- Order
  - 含义：发送行的顺序。
  - 值：`Sequential` 或 `Random`
  - 说明：`Sequential` 按文件顺序发送，`Random` 随机行发送。
- Loop
  - 含义：是否循环发送整个文件（布尔）。
  - 值：`true` 或 `false`
- LoopInterval
  - 含义：当 `Loop=true` 时，循环之间的间隔（毫秒）。
  - 类型：整数（例：`1000`）
[Hotkey]
- Enabled
  - 含义：是否启用全局热键（布尔）。
  - 值：`true` 或 `false`
  - 说明：默认热键为 `Ctrl+Shift+T`。如果启用，按下热键会在任意焦点下触发程序开始/停止发送（程序窗口需要注册热键且无冲突）。
- Countdown
  - 含义：按下热键或点击“开始”后触发发送前的倒计时（秒）。
  - 类型：整数（例：`3`）
  - 说明：倒计时期间可手动切换到目标窗口（如果使用 Active 模式）。

示例 settings.ini

    [General]
    LastFile=example.txt
    TopMost=false
    
    [Target]
    TargetMode=Active
    LockEnabled=false
    LockedWindowTitle=
    
    [Sending]
    Method=SendInput
    
    [Timing]
    DelayMin=50
    DelayMax=150
    LinePause=200
    SimulateTypos=false
    
    [Behavior]
    Order=Sequential
    Loop=false
    LoopInterval=1000
    
    [Hotkey]
    Enabled=true
    Countdown=3
    

### 常见问题与排查
1. 无法发送或目标不接收文本
   - 确认目标程序不是以管理员权限运行而本程序不是；若是，请以管理员权限运行本程序或不要以管理员运行目标。
   - 如果使用剪贴板模式但目标没有粘贴，尝试取消 `TopMost`，手动把目标输入框激活后再触发。
   - SendInput 模式通常更稳定；优先使用 `SendInput`。

2. 鼠标短暂移动或点击
   - 程序在剪贴板模式下若无法通过 API 把目标置前台，会尝试一次性移动鼠标并点击目标窗口中心以确保输入焦点。若不希望此行为，请手动在倒计时期间将光标放在目标输入框并确保目标为前台窗口。

3. 大文件发送缓慢或中断
   - 可适当增大 `DelayMax`/`DelayMin` 或 `LinePause`，或启用 `Loop` 分批发送。
   - 如需更复杂队列/分片发送可在后续版本扩展。
